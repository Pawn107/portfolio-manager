# 信号系统重构设计

日期: 2026-05-25 | 状态: 实施中

## 背景

旧系统 7 因子直接加权相加，BUY 胜率 47-50%（仅略高于随机），BUY:SELL 比例 23:1，信号分布严重失衡。

根因：
- 趋势跟随因子（HMA/MACD）和均值回归因子（RSI/量能情绪）逻辑互斥，相加后噪音对冲
- 阈值固定 60/30，不适应不同股票和不同市场环境
- 没有市场环境层做仓位调节

## 新架构：三层信号

```
第一层：市场环境（调节仓位上限）
  - 全市场涨跌比（腾讯财经指数）
  - 跌停家数估算
  - 北向资金 5 日净流向

第二层：个股技术面（决定买卖方向）
  - ADX 变化率 → 趋势/震荡模式切换
  - 趋势模式：HMA 通道突破
  - 震荡模式：RSI + 布林带均值回归
  - 筹码分布 VWAP → 支撑/阻力位

第三层：资金情绪（确认/否决信号）
  - 融资余额变化
  - 换手率异常
  - 量价背离
```

## 信号规则

- 环境层：整体情绪 → 仓位上限（0-100%）
- 技术层：ADX方向 → 选择策略 → 产生 raw signal
- 情绪层：融资+换手率+量价 → 确认或降级 signal
- 最终输出：BUY / HOLD / SELL + 建议仓位

## 实施范围

修改或新建：
- `signals/indicators.py` — 新增 ADX、布林带、VWAP 筹码分布
- `signals/scoring.py` — 重写为三层信号引擎
- `signals/risk.py` — 保留风控逻辑，对接新信号
- `pages/cn_stocks.py` — Tab1 信号展示适配新输出
